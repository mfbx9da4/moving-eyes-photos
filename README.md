## /diff

`diff.html` (served as `/diff`, or `/diff.html` locally) compares two texts or
files with GitHub-style output. Sources live in `static/diff/`:

- `algorithms/xdiff.js`: port of git's xdiff (Myers with git's heuristics,
  `--minimal`, `--patience`, `--histogram`, indent heuristic). GitHub renders
  `git diff -U3 --inter-hunk-context=1`, so "GitHub" uses Myers.
- `algorithms/intraline.js`: GitHub's word highlighting rules.
- `algorithms/difftastic/`: port of difftastic 0.71.0 on web-tree-sitter.
- `diff-worker.js` / `highlight-worker.js`: diffing and syntax highlighting
  run in workers. Like github.com, JavaScript, TypeScript, TSX, Python, Go,
  Rust, Ruby, C and CSS are highlighted with tree-sitter (`treelights.js`),
  everything else with TextMate grammars (Shiki), both mapped to GitHub's
  prettylights classes.
- `language.js` + `linguist-data.js`: linguist's language detection, data
  generated by `scripts/gen-linguist-data.mjs`.
